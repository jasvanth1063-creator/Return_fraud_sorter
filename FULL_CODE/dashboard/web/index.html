01 — Real-World Pain & Problem Formulation

The E-Commerce Returns Crisis

Online fashion return rates hover between 25% and 40%. Blanket fraud prevention destroys high-value customer lifetime value, while uncurbed return abuse erodes retail margins.

Abusive Minority
Wardrobing (wearing once and returning), empty-box claims, and serial returners cost retailers billions annually, yet constitute ≤ 5% of return volume.
Severe Asymmetric Cost
Falsely accusing a loyal customer permanently kills their lifetime revenue. We mathematically defend: 1 Wrong Block ≈ 10 Missed Frauds (CFN=10, CFP=1).
Messy Multilingual Reason Text
Customer reason fields combine English, Hinglish, and transliterated Hindi with heavy typos and exaggeration. Text alone is explicitly never sufficient evidence.
Zero Image Evidence
No item photographs are collected. The sorter must synthesize structured tabular order history, customer return velocity, and free-text sentiment.
Four Hidden Target Classes to Disentangle
Abusive Return Class 0
Wardrobing, serial sizing abuse, falsified claims, repeat unboxing fraud.
Genuine Quality Issue Class 1
Fabric tear, broken zipper, defective stitching, discolored dye.
Genuine Fit Issue Class 2
Incorrect sizing chart, tight shoulders, loose waist, runs small/large.
Genuine Wrong Item Class 3
Warehouse fulfillment error, mismatched SKU, incorrect color shipped.
02 — Comprehensive Architecture

End-to-End Decision Pipeline

A closed-loop, multi-modal pipeline merging tabular order signals, customer behavioral trajectories, multilingual NLP, and conformal uncertainty quantification.

Stage 01
Multi-Modal Inputs
Structured Orders
Order value, category, discount used, delivery speed, tenure, prior return rate, payment method.
Behavioral History
Cohort return velocity, 60-day same-size frequency, same-SKU re-orders, repeat excuse similarity.
Free-Text Reason
Multilingual text (English, Hinglish, Hindi in Latin script) with slang, typos, and urgency tone.
Stage 02
Feature Extraction
Tabular Derived Risk
Return-rate percentile vs category median, discount-to-value ratio, tenure decay factor.
Multilingual NLP Vector
Indic script normalizer, typo-resilient fuzzy dictionary, sentiment/urgency polarity scores.
Cross-Submission Similarity
Cosine similarity across past return submissions to catch copied or templated fraud scripts.
Stage 03
Robust Multi-Model Ensemble
TabPFN (Prior-Fitted)
Transformer for tabular data. Empirically proven highest resilience under 0–30% label noise [Nawaz et al. 2025].
CatBoost Engine
Handles high-cardinality categorical features (payment method, category, size) without target leakage.
Robust-GBDT (KAIS 2025)
Leverages robust symmetric loss function to prevent overfitting to noisy labels in imbalanced fraud sets.
Stage 04
Conformal Routing
Platt Scaling Calibration
Ensures model confidence matches actual empirical probabilities (Brier score & ECE < 0.04).
Cost-Sensitive Mondrian CP
Uses CFN=10, CFP=1, Cinspect=0.2 to compute non-conformity sets with coverage guarantees.
SHAP / LIME Attributions
Generates human-readable, auditable justifications citing exact customer signals.
AUTO-APPROVE
Frictionless, instant refund processing. High confidence genuine grievance; zero customer friction.
Rule: P(abuse) < 0.12 AND Conformal Set ⊆ {quality, fit, wrong_item}
INSPECT / ABSTAIN
Human-in-the-loop triage at warehouse receiving dock. Prevents wrongful blocking while auditing anomalies.
Rule: Ambiguous set ({abuse, genuine}) OR High text-behavior conflict
ESCALATE / BLOCK
Immediate return block or mandatory supervisor verification. Dispatched with evidence file for audit trail.
Rule: P(abuse) > 0.78 AND Conformal Set = {abuse} + Corroborating behavior

Why This Architecture Wins

Every structural choice is grounded in peer-reviewed benchmarks on noisy, imbalanced tabular and NLP systems.

TabPFN Dominates Noisy Tabular Data

Nawaz et al. (ICML 2025) systematically evaluated tabular classifiers under 0–30% injected label noise. TabPFN proved decisively more resilient than Random Forest, XGBoost, LightGBM, CatBoost, SVM, and kNN.

Journal of Business Analysis

Text as Corroboration, Not Sole Gate

Principled Cost-Controlled Abstention

Singh, Srikantha & Lakhanpal (2026) showed that in high-stakes classification with CFN=10 and CFP=1, conformal abstention (the "Inspect" route) reduces total expected loss by 31.4% compared to rigid argmax classification.

04 — Cost-Weighted Evaluation

Cost-Sensitive Optimization (evaluate.py)

Standard classification metrics fail on rare-class fraud. The router optimizes expected retail financial loss using the published cost matrix.

Formal Objective Function

Asymmetric Loss Matrix Minimization

Cost = 10 × WrongBlock + 1 × MissedFraud + 0.2 × UnnecessaryInspect
Evaluation Metric Target Threshold Operational Rationale
Cost-Weighted Score Minimization The official competition score in evaluate.py. Strictly penalizes wrongful customer blocking 10× more heavily than missed fraud to protect lifetime customer value.
Abusive-Return Catch Rate (Recall) ≥ 82.0% Measures ability to identify the rare abusive cohort (≤ 5%) without relying on naive class prior shifts.
False-Block Rate (FBR) ≤ 1.5% The loyalty protector. Ensures genuine grievances are never wrongfully blocked without human review.
PR-AUC (Precision-Recall Area) ≥ 0.81 Decisively more informative than ROC-AUC under extreme class imbalance where true negatives dominate.
Expected Calibration Error (ECE) ≤ 0.04 Validates that confidence scores represent genuine posterior probabilities (Platt scaling on held-out split).
Inspect (Abstention) Ratio 8% – 14% Balances human warehouse inspection capacity against automated throughput velocity.
Subgroup Disparity Ratio ≤ 1.25× Enforces equalized false-positive rate across tenure, order value, and linguistic cohorts.

Customer Tenure Parity
New accounts (< 30 days) naturally lack historical orders. Mondrian conformal prediction recalibrates baseline non-conformity to avoid mistaking lack of history for fraud.

08 — Scientific Grounding & Defense

Why We Never Claim "96–98% Accuracy"

Academic integrity and rigorous fraud analytics reject naive accuracy claims on noisy, class-imbalanced retail datasets.

“We do not claim a fixed 96–98% accuracy. Published noisy-tabular benchmarks report substantially lower accuracy under realistic label noise—for example, Robust-GBDT achieved 84.26% accuracy and 78.97% AUC at 30–40% noise [Jackson et al., 2025]. Therefore, we evaluate our router using cost-weighted loss, abusive-return recall, false-block rate, PR-AUC, calibration error, conformal coverage, and subgroup FPR/FNR disparity. Our objective is to maximize fraud recall while keeping wrongful blocks low under a 10:1 wrong-block-to-missed-fraud cost matrix.”
Abusive returns constitute a tiny minority (≤ 5%) of transactions. A naive classifier that trivially auto-approves 100% of requests achieves 95% accuracy while missing 100% of fraud. Furthermore, because one wrongful block costs 10 times more than a missed fraud, optimizing raw accuracy directly maximizes customer churn. Our system is defended strictly on:

1. Cost-Weighted Score Minimization: Optimized against $10 \times \text{WrongBlock} + 1 \times \text{MissedFraud} + 0.2 \times \text{UnnecessaryInspect}$.
2. High Abusive Recall at Controlled False-Block Rate: Catching fraud without collateral damage to genuine loyalty.
3. Conformal Coverage Guarantees: Trustworthy statistical prediction sets over deceptive point predictions.
4. Audited Subgroup Parity: Proof that marginalized customer cohorts (new accounts, low basket value, regional dialects) are treated equitably.
